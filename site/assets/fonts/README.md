# Fonts

The landing page self-hosts WOFF2 subsets (latin and latin-ext) so it makes no
third-party font requests at runtime. All three families are licensed under the
SIL Open Font License 1.1. The full license text is in [OFL.txt](OFL.txt).

| Family | Upstream | Copyright |
|---|---|---|
| Inter Tight | <https://github.com/rsms/inter> | Copyright (c) 2016 The Inter Project Authors |
| Instrument Serif | <https://github.com/Instrument/instrument-serif> | Copyright 2022 The Instrument Serif Project Authors |
| JetBrains Mono | <https://github.com/JetBrains/JetBrainsMono> | Copyright 2020 The JetBrains Mono Project Authors |

The files were downloaded from the Google Fonts API and subsetted to the ranges
needed by the site. No font binaries were modified beyond subsetting.
